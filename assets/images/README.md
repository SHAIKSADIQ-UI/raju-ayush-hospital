# Images Asset Store

This directory is used to store image assets for the WH Healthcare Service website.

## Directory Structure
- `/assets/images/` - Place all static images (PNG, JPG, JPEG, SVG, WebP, GIF) here.

## How to Reference Images in HTML/CSS
You can link to these local image assets using relative paths:

### In HTML:
```html
<img src="assets/images/your-image.jpg" alt="Description">
```

### In CSS:
```css
.hero-section {
    background-image: url('assets/images/hero-bg.jpg');
}
```
